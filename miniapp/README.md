# 微信原生小程序

## 打开方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本目录 `miniapp/`。
4. 当前 `project.config.json` 使用 `touristappid`，接入登录前替换为正式小程序 AppID。

## 当前页面

- 今日：到期摘要、快捷入口和重点食材。
- 食材：按冷藏、冷冻和常温筛选。
- 我的：家庭、设备和设置入口。
- 待办：从“我的 → 水墨屏显示 → 食材管理 → 管理待办”进入，维护水墨屏食材
  模式下显示的家庭待办事项。
- 快速记一笔：解析新增、消耗和丢弃，确认后更新库存。
- 导入订单：最多选择 9 张图片，异步识别并确认后批量入库。
- 设备：绑定与配网入口。
- 墨水屏相册：从“水墨屏显示 → 独立相册 → 管理相册”进入，上传、预览确认、
  删除、排序并设置轮播周期。
- 行情看板：数字货币、美股、A 股和港股可按代码或名称分别搜索，常用指数保留
  快捷添加；家庭成员可选择最多 6 项，逐项删除、调整顺序，并设置 15/30/60
  分钟刷新周期和夜间暂停。
- 课程表：家庭成员可自定义上午、下午节数和每节时间，按星期填写课程名称与简短
  备注；可选择竖屏三日或横屏一周显示，并提供对应真实预览。
- 水墨屏显示：从“我的”进入，在食材管理、完整简版黄历、七日天气、一周课表、
  行情看板、独立相册之间切换，并显示对应预览和管理入口。

## 本地 API

`config.local.js` 保存当前 Mac 的局域网 API 地址，已被 `.gitignore` 忽略：

```js
module.exports = {
  apiBaseUrl: "http://192.168.1.100:8000",
  enableDevLogin: true
};
```

Mac 地址改变时，只修改该文件。微信开发者工具已设置 `urlCheck: false`，用于本地
HTTP 联调；发布正式版前必须改用已备案的 HTTPS 域名并恢复域名校验。

正式页面使用带登录态和家庭空间隔离的 `/v1/households/{id}/...` 接口。食材页
可新增、编辑、筛选和删除库存；任何已确认的库存修改都会生成新的设备画面
ETag。订单图片由小程序逐张上传，服务端识别完成后会删除原图。

墨水屏相册面向同一家庭的全部有效成员开放。每个家庭最多保存 6 张 JPG/PNG，
单张不超过 5MB。上传后必须先核对后端生成的 3:5 四色预览，再点击“确认加入
轮播”。在“水墨屏显示”中选择独立相册后，墨水屏只显示照片。轮播周期可选
1、3、6、12、24 小时，
也可以对任意已确认照片点击“立即显示”。私有照片只经带登录态的后端接口下载，
小程序不保存 COS 地址或访问密钥。

“我的 → 水墨屏显示”对同一家庭的管理员和普通成员开放，并按当前选择显示食材
内容或真实日期黄历预览。选择完整简版黄历后，
墨水屏会全屏显示公历、农历、干支、生肖、节气/节日、宜、忌和冲煞；该模式不
叠加食材、待办、小程序码或照片。家庭成员还可以手动搜索城市，在黄历顶部启用
当天的天气、温度与降雨概率；天气服务来源仅在小程序设置区展示，不写入水墨屏
底部。切换不需要重新烧录 ESP32 固件。

行情管理入口位于“我的 → 水墨屏显示 → 行情看板 → 管理行情”。上涨使用红色，
下跌使用黑色，黄色边框表示 24H、盘中、收盘或延迟状态。报价是定时行情快照，
不是交易报价；家庭成员均可修改自选列表和刷新周期。

课表管理入口位于“我的 → 水墨屏显示 → 一周课表 → 管理课表”。家庭成员均可
编辑上午、下午节数、各节时间、课程名称和简短备注，并选择显示方向。竖屏显示
今天、明天和后天，横屏显示周一至周日；保存至少一门课程后才允许切换到课表
模式。ESP32 固件无需更新。
