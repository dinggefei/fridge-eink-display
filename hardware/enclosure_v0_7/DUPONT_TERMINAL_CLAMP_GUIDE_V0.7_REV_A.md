# V0.7 ESP32 免焊杜邦公端子定位压板 Rev A

本附件不改变 V0.7 的前框、中托、后盖、器件位置和 `120 × 184 × 19 mm`
外形，只利用 ESP32 左侧原有两个安装孔增加可拆卸绝缘压板。

## 需要准备

- 8 根公对母杜邦线，建议 `26～28 AWG`；
- 2 颗 `M2×6 mm` 自攻螺丝，用于 ESP32 左侧；
- 2 颗原有 `M2×4 mm` 自攻螺丝，用于 ESP32 右侧；
- 小针或杜邦端子退针工具；
- 万用表。

## 必须先打印检具

先打印：

- `fit_test_dupont_terminal_base_v0_7_rev_a.stl`
- `fit_test_dupont_terminal_clamp_v0_7_rev_a.stl`

打印参数：PETG、0.4 mm 喷嘴、0.16 mm 层高、4 道墙、100% 比例。将压板旋转到
C 形开口朝上打印，不需要支撑。

检具模拟了 ESP32 约 `1.6 mm` PCB 厚度和 V0.7 中托约 `2.8 mm` 板下净空。
三根金属公端子应能自然穿过检具孔，锁紧后针尖不得接触检具底板。

## 处理杜邦线

1. 不剪线、不剥线，也不破坏已经压接的金属端子。
2. 用针压住公头黑色 1P 外壳上的金属倒钩。
3. 从外壳后方轻轻抽出完整金属公端子。
4. 检查压线翅没有松开、铜丝没有外露或断裂。
5. 母头仍保留原塑料外壳，用于插入 DESPI-C02 排针。

## 安装正式压板

1. 断开电池和外部 USB-C，Lipo Rider 开关置于 `OFF`。
2. ESP32 天线端仍朝设备顶部，USB-C、BOOT、RESET 仍朝设备下方。
3. 先用右侧两颗 `M2×4 mm` 轻轻定位 ESP32，不要锁死。
4. 按现有固件接线，依次把 8 个公端子插入 `3V3、GPIO7、GPIO8、GPIO9、
   GPIO10、GPIO11、GPIO12、GND`。
5. 将压板的 C 形开口朝向 ESP32 板内侧；两端螺丝孔对准左上、左下安装孔。
6. 金属端子的压接段应落在压板的绝缘槽内，线束从开口侧向 DESPI-C02 引出。
7. 轻轻把线束拉向 DESPI-C02，使方形公针贴住排针孔内壁。
8. 用两颗 `M2×6 mm` 交替逐步锁紧；压板刚停止移动即停手，不得压弯 PCB。
9. 最后轻轻锁紧右侧两颗 `M2×4 mm`。

## 接线表

| DESPI-C02 | ESP32-S3 N16R8 |
|---|---|
| `BUSY` | `GPIO9` |
| `RES` | `GPIO7` |
| `D/C` | `GPIO8` |
| `CS` | `GPIO10` |
| `SCK` | `GPIO12` |
| `SDI` | `GPIO11` |
| `GND` | `GND` |
| `3.3V` | `3V3` |

`3.3V` 禁止连接到 `5V`、`VIN` 或 `VBUS`。

## 通电前验收

1. 万用表短接表笔，记录表笔自身电阻。
2. 逐根测量 ESP32 焊盘到 DESPI-C02 对应针脚，附加接触电阻应尽量不超过
   `0.2 Ω`，且轻轻移动线束时读数不应跳变。
3. 任意相邻信号之间、`3V3` 与 `GND` 之间不得短路。
4. 确认 8 根针脚均未接触中托或屏幕背面。
5. 装上后盖前，完整刷新水墨屏至少 3 次；不得出现 ESP32 重启、BUSY 超时、
   屏幕不刷新或 DESPI-C02 供电下降。

任一项目失败，都不要继续封装设备。免焊压接的长期抗振性仍低于规范焊接连接，
送给他人使用前应额外完成开关冰箱门和轻摇线束测试。
