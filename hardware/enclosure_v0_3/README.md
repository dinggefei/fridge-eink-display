# 冰箱食材清单外壳 V0.3

V0.3 按 2026-08-15 确认的实物摆放重新设计。**V0.1 正面边框继续使用**，只替换：

- `middle_carrier_v0_3.stl`：中层托板。
- `rear_cover_v0_3.stl`：顶部中央 USB-C 充电口后盖。

## 已确认的布局

- 顶部中央：Lipo Rider Plus，USB-C 输入口位于外壳顶部中线。
- 左侧中部：ESP32-S3，天线朝上、Type-C 朝下。
- 右侧中部：DESPI-C02，FPC 接口朝右并直连屏幕排线。
- 下部：806090 电池横放。
- ESP32 与 DESPI 的板边净距为 7 mm，兼顾短 SPI 线和装配空间。

坐标和孔位详见 `output/manifest.json`；1:1 实物定位图为
`output/placement_template_v0_3_1to1.svg`，打印时必须选择“实际大小/100%”，禁止“适合页面”。

## 严格打印顺序

完整托板和后盖暂时标记为“待检具通过”，不要直接下单整件。

1. 只打印 `fit_test_lipo_top_port_v0_3.stl`，材料和层高与正式件一致。
2. 用 4 颗 M2 × 4 mm 自攻螺钉安装 Lipo Rider Plus；USB-C 必须朝检具立墙。
3. 检查四孔能自然对正，螺钉不顶穿；不能靠拧螺钉强行拉正电路板。
4. 插入常用 USB-C 充电线，插头应能完全插入，四周不顶住开孔。
5. 检具通过后，再打印 `middle_carrier_v0_3.stl` 和 `rear_cover_v0_3.stl`。

若检具不通过，只修改小检具和参数，不浪费完整外壳打印费用。

## 建议打印参数

- 材料：PETG。
- 喷嘴：0.4 mm。
- 层高：0.20 mm。
- 壁数：4。
- 顶层/底层：5。
- 填充：25% Gyroid。
- 自动缩放：关闭，STL 单位为毫米。
- 中层托板：大平面贴打印平台，关闭支撑。
- 后盖：贴冰箱的一面朝下；仅充电孔处按切片结果增加局部支撑。
- 充电口检具：底板贴打印平台；立墙开孔允许短距离桥接。

## 装配顺序

1. 屏幕放入 V0.1 前框，并用 0.5 mm EVA 泡棉胶隔离玻璃边缘。
2. 安装 V0.3 中层托板。
3. 先将屏幕 FPC 插入 DESPI-C02 并锁紧，再固定 DESPI；FPC 不折死、不受拉力。
4. 固定 ESP32，天线区域不覆盖泡棉、电池或导线。
5. 用四颗 M2 × 4 mm 自攻螺钉固定 Lipo Rider；USB-C 朝外壳顶部。
6. 用两条 10～12 mm 魔术贴扎带固定电池，电池与托板之间垫 0.5 mm EVA。
7. 使用短 SPI 线连接 ESP32 与 DESPI，走线不得跨过 ESP32 天线。
8. 用短 USB-A 转 Type-C 线连接 Lipo Rider 输出与 ESP32；电池插头确认正负极后再接入。
9. 桌面通电验证后合上 V0.3 后盖，确认顶部充电线可正常插拔。

## 安全要求

- 电池不得被螺柱、后盖、扎带或导线挤压。
- 所有电路板底部加绝缘片，避免焊点接触屏幕金属背板。
- 电池出现鼓包、破损、异常发热或异味时，立即断电并停止使用。
- Lipo Rider 板载开关原型阶段保持 ON；V0.3 不擅自增加外置开关功能。
