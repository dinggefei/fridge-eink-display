# V0.9 超薄外壳排布研究

本目录是独立的超薄方案，**不会覆盖或修改 V0.7**。在原排布研究基础上，
现已生成 `15.0 mm` 厚的 V0.9 工程样机 STL；仍须先打印四个局部检具。

## 精算结论

- 保留现有 `8 mm` 电池、`1 mm` 双面胶和 `2 mm` 软磁片时，建议下限为
  `15.8 mm`；继续压缩会减少锂电池安全余量。
- 将电池胶改为不超过 `0.2 mm` 的丙烯酸转移胶后，正式目标可以做到
  `15.0 mm`；本次加厚后，电池与磁片槽之间保留 `0.8 mm` 名义余量。
- 同样使用 `0.2 mm` 转移胶并把电池余量压到 `0.8 mm`，可以制作
  `14.8 mm` 工程样机，但在完成长期充放电和温升测试前，不用于送人设备。
- 若还要做到约 `13.8 mm`，必须同时换成约 `1 mm` 厚的软磁片；这已经改变
  当前确认的磁吸物料，需要重新验证冰箱门上的抗下滑能力。

## 15.0 mm 工程样机方案

- 外轮廓保持 `120×184 mm`。
- 三片软磁片的平面位置与 V0.7 相同：两片 `90×50×2 mm` 位于下部，
  一片 `50×20×2 mm` 位于右上。
- 磁片外侧 PLA 加厚到 `0.6 mm`。
- 前框可见面改为 `1.0 mm`，四颗螺丝柱根部采用局部锥形加强，不把整片前框加厚。
- 中托安装基准位于前外观面后 `2.6 mm`，与屏幕定位凸起顶面一致。
- 中托普通区加厚到 `1.2 mm`；电池下方局部底板加厚到 `0.6 mm`。
- 电池固定胶必须从 `1.0 mm` 泡棉胶换成 `≤0.2 mm` 转移胶。
- ESP32 免焊压板需要重新设计，将板下净空从 `2.8 mm` 降至 `1.4 mm`；
  金属端子仍不得接触中托或屏幕金属背板。
- Lipo Rider 螺丝柱高出中托表面 `0.6 mm`，柱顶模型 Z 为 `1.8 mm`；
  ESP32 柱顶模型 Z 为 `2.6 mm`，板下净空仍为 `1.4 mm`。
- 外壳改用四颗 `M2×12 mm` 自攻螺丝；沉孔深 `1.6 mm`、前框螺丝柱
  顶面距外观面 `4.6 mm`，理论咬合约 `3.2 mm`。
- Type-C 开口净尺寸沿用 V0.7 的 `11.5 × 7.5 mm`；根据 V0.9 中托和
  Lipo Rider 新安装基准重新计算，后盖模型 Z 中心为 `6.6 mm`。
- 后盖普通面加厚到 `1.0 mm`，左侧补强带加厚到 `1.2 mm`；整体外形厚度
  仍为 `15.0 mm`。
- BOOT、RESET 改为与后盖一体打印的半封闭悬臂按键；周围开 `270°`、
  宽 `0.8 mm` 的圆弧贯穿槽，上方保留 `90°`、厚 `0.4 mm` 的连接桥。
  内侧 `Ø1.8 mm` 按压杆从后盖内表面伸出 `4.5 mm`，杆端带 `0.2 mm`
  倒角，模型名义静止间隙为 `0.7 mm`。
- Lipo Rider 指示灯开孔保持原下边缘不动，只将上边缘下移 `3 mm`；开孔
  为 `5.2×18 mm、R1 mm`，圆角之间的直边由 `19 mm` 改为 `16 mm`。

## 文件

- `previews/layout_and_thickness_study_v0_9.png`：排布和厚度方案说明图。
- `feasibility_report_v0_9.json`：加厚前的初版高度研究记录；当前打印尺寸以

- `generate_layout_study_v0_9.py`：可重复生成加厚前的初版研究文件。
- `generate_enclosure_v0_9.py`：生成独立 V0.9 STL、清单和打印包。
- `validate_enclosure_v0_9.py`：检查 STL 水密性、外形、Type-C 参数和螺丝咬合量。
- `output/`：生成结果。
- `RFM_enclosure_v0_9_STL.zip`：交付打印包。

正式打印后盖前，先打印 `fit_test_boot_reset_buttons_4p5mm_v0_9.stl` 和
`fit_test_lipo_indicator_opening_5p2x18_v0_9.stl`，分别验证按键空行程、独立
触发和最上方指示灯的实际可见范围。

## 当前停止条件

以下任一条件出现时，不得生成正式完整 STL：

1. 电池加选定胶层的实测最大厚度超过 `8.2 mm`；
2. 新免焊压板仍需要超过 `1.4 mm` 的 ESP32 板下空间；
3. 金属端子可能接触中托或水墨屏金属背板；
4. M2×12 mm 螺丝实测咬合不足 `3.0 mm` 或发生顶底。
