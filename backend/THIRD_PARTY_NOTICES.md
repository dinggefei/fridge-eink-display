## Market data services

Cryptocurrency quotes may be supplied by CoinGecko. Display attribution:
"Data provided by CoinGecko". API documentation and current terms:

- https://docs.coingecko.com/reference/simple-price
- https://www.coingecko.com/en/terms

Stock and index quotes may be supplied by Twelve Data. API documentation and
current terms:

- https://twelvedata.com/docs/introduction/overview
- https://twelvedata.com/terms

Stock and index quotes may also be supplied by the Longbridge OpenAPI Python
SDK, which is dual-licensed under Apache-2.0 and MIT. API documentation,
source code and current terms:

- https://open.longbridge.com/zh-CN/docs/quote/overview
- https://github.com/longbridge/openapi
- https://longbridge.com/terms

API access does not by itself grant every redistribution or public-display
right. The production operator must keep an appropriate plan and verify the
terms for each exchange and use case before enabling the market dashboard.
