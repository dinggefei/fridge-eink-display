# 七日天气模式

2026-09-15：按已确认的七日布局完成实现并部署生产。数据库已迁移至
`0014_weather_display`，生产真实七天接口、PNG 预览和设备帧已通过服务端验证；
未上传新版小程序、未切换任何家庭的显示模式、未做实体屏验收。

## 产品边界

- 新增独立 `weather` 模式：城市、今天放大、未来六天列表、预报获取时间。
- 固定今天加未来六天；只显示天气，不放黄历、行情、食材或小程序码。
- 家庭成员均可选择城市和显示模式。沿用黄历城市，但不依赖或改变黄历天气开关。
- 小程序使用后端同一渲染器输出的 480×800 PNG 预览，设备接收 800×480、96,000 字节四色帧。
- 保持已确认布局，不额外加入降水概率列。雨雪天气用红字标记；缺失值显示“暂无预报”，不当成晴天或 0℃。

## 数据与刷新

- 沿用和风天气 `/weather/v1/daily/{lat}/{lon}`，参数 `days=7`、`localTime=true`。
- 使用现有中国城市搜索和北京时间显示规则。真实账号七天接口权限/计费仍待联调确认。
- 按天气服务和经纬度（小数点后两位）共享数据库缓存，数据库锁避免并发重复查询。
- 默认每 3 小时更新；跨日重新获取；失败后 15 分钟重试，12 小时以内保留有效日期的缓存并注明“更新延迟”。
- 超过缓存期限显示缺失占位；跨天不把昨天的数据移到今天。
- 设备仍每 5 分钟检查。帧 ETag 按最终像素生成；未变化返回 304，不刷新屏幕。
- 小程序天气来源入口保持可见。预览 PNG 需要家庭成员登录，并禁止公共缓存。
